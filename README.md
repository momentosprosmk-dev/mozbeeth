# MOZBEETH - Productor Musical & Estudio

Arquitectura modular MomentosPro con hojas de estilo separadas para Móvil (`<= 1024px`) y PC (`>= 1024px`).

## Estructura del Proyecto
- `/` — Portal principal (`index.html`)
- `/catalogo/` — Catálogo de instrumentales por género (`categorias`, `reggaeton`, `trap`, `rnb`, `synthwave`)
- `/servicios/` — Servicios de producción, mezcla, mastering y planes de licencias
- `/creditos/` — Créditos y lanzamientos destacados
- `/estudio/` — Equipamiento y filosofía de trabajo
- `/formularios/cotizar/` — Formulario de reserva y cotización conectado a WhatsApp
- `/recursos/` — Archivos centralizados (`css/`, `html/`, `js/`, `json/`, `media/`)
